# TaskFlow

TaskFlow is a Java application for managing projects, tasks, and developer learning roadmaps.

The project is being built as a hands-on way to practice software engineering concepts with Java and professional Git/GitHub workflows.

## Current Status

🚧 In development — the core domain model is the next milestone.

## Technologies

- Java 21
- Maven
- Git & GitHub

## Planned Concepts

- Object-Oriented Programming
- Collections and Generics
- Streams and Lambdas
- Exceptions
- File persistence
- Concurrency
- JUnit
- Mockito
